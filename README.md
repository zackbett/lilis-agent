# ✮ LILIS

Autonomous **Web3 AI agent** designed to interact with onchain applications.

LILIS explores the intersection of **AI agents, web3 automation, and adaptive systems**.

---

## ✦ capabilities

✮ NFT mint automation  
✮ onchain interaction  
✮ wallet inspection & analysis  
✮ modular skill system  
✮ dynamic skill loader  

---

## ✦ architecture

LILIS follows a modular agent architecture:
The agent dynamically loads skills depending on the task it needs to perform.

---

## ✦ project vision

LILIS aims to become an **autonomous web3 operator** capable of:

- discovering opportunities  
- interacting with decentralized apps  
- executing onchain actions
